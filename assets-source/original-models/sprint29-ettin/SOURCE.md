# Ettin body replacement and preserved earlier head source

## Current construction, 2026-10-22

The owner rejected the appended head. Production now compiles
`EttinBodyMesh.cs`, replacing the exact Ettin instance's complete visible Hill
body with one private connected surface. Both detailed adult faces are reshaped
from the installed readable mesh: a broader jaw on one head and a taller,
narrower face with an asymmetric nose on the other. Two neck branches join a
shared, relaxed shoulder surface. Both heads use the same original native
atlas as the body. The native first head is removed from the visible surface;
there is no retained third head or appended primitive mask.

The algorithm contains no extracted native geometry, UV arrays, pixels or clips.
It reads only the exact installed `hill_giant_1` mesh (2,886 vertices / 4,248
triangles), subdivides that topology, branches it at the authored shoulder
section, closes the two branch endpoints and smooths only the junction.
It preserves lower-body shape, copies native skin/UV channels, normalizes all
weights, and supplies two private Neck/Head/Jaw/JawEnd branches on the original
rig. Each branch copies native local poses with a fixed neck origin. The source
body renderer alone is suppressed after successful material-controller adoption.
Weapons, clothing, native mesh/material resources and colliders remain native.

Private offline previews were generated by **the actual C# BuildData method**,
using locally decoded installed input, then inspected from front, side, rear,
three-quarter and gameplay-like distance. Synthetic neck/head/jaw poses are
explicitly offline stress previews. No native asset or decoded preview input is
committed. Current output has 14,082 UV/skin vertices and 24,652 triangles; this
is evidence of these inputs, not a product assertion. Native qualification and
owner approval are recorded in the existing mission acceptance table.

The exact source cached fade baseline and the demonstrated paired native
queue/tag transition remain enforced. The new renderer owns one material and
borrows unchanged native maps; it creates no texture. Teardown restores the
source renderer and releases the private mesh, material and both branch roots.

provenance but are no longer compiled into production.

integrated jaw, nose/cheeks, brow ridges and small ears, plus a receding
