# Sprint 23 original icon sources

The Triceratops and Stegosaurus source paintings were generated with the
built-in image-generation capability from project-authored composition briefs.
No game or third-party image was supplied as a reference. The shared catalog
prompt required a full-bleed square CRPG summon icon, painterly high-fantasy
realism, dramatic rim light, atmospheric radial background, bronze circular
frame, centered readable silhouette, no text, watermark, logo, generic paw,
extra creatures or copied game art.

The creature-specific briefs are preserved verbatim as `subjectPrompt` entries
in `prompts/icon-prompts.json`. Triceratops is front-weighted around its three
horns and frill; Stegosaurus is lateral so the plate row and four-spiked tail
cannot read as the protected Ankylosaurus club-tail concept. The immutable
source files are:

- `sources/triceratops.png`, SHA-256
  `ea9cf4092ed5bd96e00138e1a471eec0aa136d78e7c3a8b81ea3a07fa4695e40`
- `sources/stegosaurus.png`, SHA-256
  `da97b11601d76fdbb5456ec413ebf32cfd3fd6d0432db46f2f0bef5526978d7f`

The deterministic export script produces the runtime 128-by-128 RGBA PNGs and
records their exact consumers. Technical and native presentation checks do not
constitute owner aesthetic approval; that remains
NOT_PERFORMED_NONBLOCKING.
