# Semantic icon source

Generated 2026-08-02 using the built-in OpenAI image tool as one 3-by-2 sheet: Nimble boot/feather; Bonus Feat star/parchment; Gun Training target/sights/ball; True Grit battered coin/gloved fist; Rapid Reload ramrod/circular arrow; Firearm Weapon Focus round ball/target. Palette: muted salmon, antique gold, brown, cream, gunmetal, dark linework. Flat green background; no text, guns, crossbows, glossy or modern UI artwork.

Equal cells were cropped, green pixels changed to alpha, and each icon deterministically resampled to 60×60 centered on a transparent 64×64 canvas using .NET `System.Drawing` bicubic interpolation. Exports are in `assets/game/icons/`.
