# Sprint 88 battered runtime-use resolver

Resolve one concrete firearm's engine GUID and consult only an already-existing
save-owned ownership carrier. An unbound item remains ordinary. A bound item
compares the exact persisted origin identity against the exact current user's
stable unit identity and delegates effective condition/value behavior to the
qualified domain policy. Missing identity evidence fails closed; evaluation
never creates persistence state and never infers ownership from equipment.

This adapter is qualified by focused source checks, the domain policy suite,
repository validation, clean Release build, and strict package validation.
Subsequent checkpoints inject its decision at firing/action and economy
boundaries without changing actual persisted firearm condition.
