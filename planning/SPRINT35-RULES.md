This contract keeps four things separate: printed Pathfinder First Edition
requirements, the installed Kingmaker 2.1.7b surface, already accepted project
adaptations, and Sprint 35 decisions proposed for native proof. Source entries:
[Barbed Devil](https://www.aonprd.com/MonsterDisplay.aspx?ItemName=Barbed%20Devil%20(Hamatula)),
[Bone Devil](https://www.aonprd.com/MonsterDisplay.aspx?ItemName=Bone%20Devil%20(Osyluth)),
[Wall of Ice](https://legacy.aonprd.com/coreRulebook/spells/wallOfIce.html),
[Summon Monster](https://legacy.aonprd.com/coreRulebook/spells/summonMonster.html), and
[Universal Monster Rules](https://legacy.aonprd.com/bestiary/universalMonsterRules.html).
These sources do not prove installed behavior.

## Lifetime classes

| Class | Owner and termination |
|---|---|
| Active summon-owned aura, wall, residual breach area, temporary ability grant, private wall/model view | Exact source instance plus summoner boundary; ends on its native duration or source/summoner retirement, module disable, area teardown, or explicit destruction as applicable; cleanup is idempotent and safe after native destruction |
| Fear repeat-memory marker | Exact aura source and recipient; expires with its specified repeat window/source contract, without suppressing another source |
| Grapple link | Exact holder, target and limb/slot; safe reload resets both participants and owned slots; no hold re-establishment claim |
| Poison instance | Exact sting source is recorded for attribution, but its finite native course and cure saves are independently timed; source disappearance is not a cure or dispel |
| Applied hit-point or Strength damage | Native game state governed by healing/restoration, not erased by source or module cleanup |
| Ability resource | Exact summoned unit instance; native spend persists across modes and save/load for that summon and cannot reset by toggling the command |
