# Sprint 90 battered firearm misfire overlay

the exact discharge result. It governs the Broken misfire threshold and
condition consequence while the repository transaction still compares and
commits the exact actual item state.

a misfire produces the existing `BrokenToWrecked` consequence and explosion
contract. An advanced firearm in the same overlay retains its actual condition,
matching the established advanced Broken behavior. Effective Wrecked firearms
remain unable to register because discharge rejects them first.
