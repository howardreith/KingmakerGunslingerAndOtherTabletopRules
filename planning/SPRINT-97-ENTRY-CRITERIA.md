# Sprint 97 atomic native Scatter Shot transaction

Compose the qualified PnP distance, native cone geometry, pure target/volley
policies, item-owned state, and marked native attacks into one production
runtime transaction. All native targets are resolved before state mutation;
one chamber is consumed total; every target receives one native weapon attack
at -2 with precision damage disabled, and the custom action never dispatches a
Vital Strike ability; misfire changes condition only when every roll misfires; a Broken to
Wrecked all-misfire burst uses triple base weapon dice; item state rolls back
on delivery faults and no retry is attempted.

This checkpoint does not yet register/grant the player-facing ability or unlock
the production item. Qualification requires a focused source contract,
repository validation, all tests, clean exact-reference Release build, strict
package validation, and staged safety audits.
