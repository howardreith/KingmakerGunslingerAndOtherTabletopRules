# Codex handoff: Kingmaker icon overhaul

This bundle contains the copy-ready mission prompt and all five full-resolution screenshots supplied for the work.

## Recommended use

1. Extract this folder into the Gunslinger repository as `docs/reference/icon-overhaul/` so the relative paths in `CODEX_PROMPT.md` remain readable. Keeping it outside the repository is also fine if Codex is given the absolute folder path.
2. Whitelist or create the local branch `codex/icon-art-overhaul`.
3. Start Codex at the repository root and give it the contents of `CODEX_PROMPT.md`.
4. Leave the `references/originals` PNGs available to Codex. They are the full-resolution visual source; `references/CONTACT_SHEET.png` is only a quick index.

The prompt forbids all remote mutations and asks Codex to preserve old Rifle/Revolver blueprints when necessary for save/Toy Box compatibility while removing them from ordinary gameplay.
