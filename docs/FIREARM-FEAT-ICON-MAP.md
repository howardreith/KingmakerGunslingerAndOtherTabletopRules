# Firearm feat icon map
Human review superseded the 0.0.88 dark circular badge treatment. The current parameter assets reconstruct the accepted Nodachi selector contract documented in CustomWeaponSelectorRuntime: a native category monogram presentation, rendered as original deterministic project art so stable explicit firearm feature blueprints need not be replaced. Pistol, Musket, Blunderbuss, Rifle, and Revolver use calligraphic P, M, B, Ri, and Rv marks on aged pale fields. Rapid Reload uses a separate oxblood return-arrow/ramrod glyph with blue corner accents. The contact sheet shows exact 64- and 32-pixel rows; final aesthetic acceptance remains human-gated.

`EDC404430317C2E1A35D51F675E631FACA49D0D9E440BCF9ADBA606E696A9EE2`.
