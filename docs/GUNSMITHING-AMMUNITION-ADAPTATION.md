# Gunsmithing ammunition adaptation

`Craft Basic Firearm Ammunition` is granted by Gunsmithing. A conscious, able
character outside combat may work for one uninterrupted minute once per rest
while the shared inventory contains a non-consumable Gunsmith's Kit.

Successful completion atomically spends 22 gp—10% of the ordinary combined
purchase value rounded conservatively—and grants 20 Black Powder Charges and
20 Lead Balls. Interruption before completion changes nothing. Failed gold or
inventory completion rolls back the transaction. The persisted entitlement is
cleared by native rest application. Basic project ammunition has zero resale
value, preventing conversion of crafted batches into profit.

`Craft Paper Cartridges` uses the same shared entitlement. It atomically spends
24 gp (10% of the 240 gp retail value) for 20 Paper Cartridges. Native
Gunsmithing and the scoped CMI route use this same positive, discounted rule;
insufficient gold leaves money, inventory, and the entitlement unchanged.

No firearm crafting or advanced-ammunition system is introduced by 0.0.66.
