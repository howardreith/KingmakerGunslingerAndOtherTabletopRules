# Kingmaker Gunslinger 0.0.95

This is the first owner-published GitHub release of Kingmaker Gunslinger and its
independent tabletop-rules modules for Pathfinder: Kingmaker 2.1.7b.

## Highlights

- Implements the complete Gunslinger class progression, grit, deeds, firearm
  proficiency, early and advanced firearms, ammunition, paper cartridges,
  reload and maintenance, misfire state, firearm crafting, campaign acquisition,
  native-style weapon presentation, and project-owned firearm audio.
- Includes Mysterious Stranger, Pistolero, and Musket Master archetype support.
- Adds selectable Bodyguard and In Harm's Way feats with independent persistent
  automation modes, native attack-of-opportunity expenditure, truthful
  attack-detail AC attribution, original-delivery redirection, and a
  turn-aware off-turn immediate-action adaptation.
- Integrates ordinary Aid Another and Bodyguard with compatible Call of the Wild
  and Favored Class Helpful traits, including the halfling +4 replacement
  behavior and independent contributors.
- Adds Acadamae Graduate and the Cord of Stubborn Resolve.
- Adds Shield Other with conserved finalized HP splitting and durable link
  validity.
- Expands Summon Monster I-IX and Summon Nature's Ally I-IX with project-owned
  icons and additive, save-stable choices.
- Adds Elven Branched Spears, Wakizashi, Katana, Nodachi, named magic weapons,
  campaign distribution, and optional compatibility bridges.
- Adds the native Urban Barbarian archetype.
- Adds Brown-Fur Transmuter when a structurally compatible Call of the Wild
  installation is present.
- Provides nine independent UMM feature modules. All default enabled; saved
  changes take effect after a complete Kingmaker restart.

## Compatibility

- Pathfinder: Kingmaker Enhanced Plus Edition 2.1.7b
- Unity Mod Manager 0.32.4 / supported 0.32.x line
- Harmony 1.2 through `0Harmony12.dll`
- .NET Framework 4.7
- Windows Steam installation used for qualification

The mod remains standalone. Call of the Wild is required only for Brown-Fur
Transmuter and is otherwise an optional compatibility input. Favored Class,
Tweak or Treat, Arms & Armor, and Toggle Custom Soundpacks have narrow,
version-specific compatibility evidence documented in the repository. This
release does not claim compatibility with every build of every third-party mod.

## Installation

1. Download the `KingmakerGunslinger-0.0.95-bodyguard-in-harms-way.zip` file from **Assets** below.
2. Close Pathfinder: Kingmaker.
3. In Unity Mod Manager, select Pathfinder: Kingmaker.
4. Drag the downloaded ZIP into the Mods tab.
5. Launch Kingmaker and confirm **Kingmaker Gunslinger 0.0.95** loads without a
   red error indicator.

Do not download GitHub's automatically generated **Source code** archives; they
are not Unity Mod Manager packages.

Do not merge selected files into an older installation. Install the complete
ZIP as one `KingmakerGunslinger` mod directory.

## Save warning

This mod publishes save-owned classes, archetypes, feats, spells, buffs, items,
weapon categories, summons, enchantments, resources, and firearm-state
identities. Disabling an individual feature module preserves those identities,
but uninstalling the entire mod from a campaign that used its content is not
generally safe. Keep the same version or a compatible newer version installed,
or return to a save created before the mod was introduced.

## Release policy

Version `0.0.95` is a permanent release identity. Later improvements must use a
new version and new assets rather than replacing the bytes attached to this
release.
