The item name, outer square frame, selection outline, availability thumb and progression markers are separate UI elements. Native emblem internal rings/details are artwork; use their weight/spacing vocabulary without copying pixels.

Read-only installed-assembly inspection established `FeatureUIData`'s explicit null-icon overload and `CharBuildSelectorItem.SetIcon`'s native `m_AcronimText` route. The native UI applies `UIUtility.GetAbilityAcronym`, its own font asset, name-based background/color, and state overlays. Default selected-feature `FeatureUIData` independently uses the parameter blueprint sprite. Preserve that contract until its own surface is qualified. Do not render an approximate PC font and call it native evidence.
