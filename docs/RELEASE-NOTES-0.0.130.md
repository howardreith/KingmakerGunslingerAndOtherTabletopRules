# Kingmaker Gunslinger 0.0.130 — Icon Art Overhaul (full release)

Owner-authorized full public release for the complete icon art overhaul.
UMM version `0.0.130`, informational version
`0.0.130-icon-art-overhaul`. All gameplay systems from 0.0.129 are preserved
unchanged, including the v0.0.129 Recall, automatic scroll reader and Oracle
behavior.

## What is in this release

- **90 owner-approved images** (89 hand-authored paintings plus the Rapid
  Reload emblem), each frozen against exact source/export hashes in the
  repository approval records. No prior artwork was altered; protected
  legacy art, native spell reuse, eastern lettering, meshes, audio and VFX
  are unchanged.
- **Complete consumer integration** across racial actions, variants,
  held-touch deliveries, activatables, racial feats, heritages, alternate
  traits, selectors, buffs and scroll items; the canonical catalog records
  284 exact consumer dispositions, and the guarded runtime census verified
  the 137 painted assignments and all protected/native-reuse bindings on the
  released artifact.
- **Native P/M/B monogram presentation** for the five integrated firearm
  feat roots (Weapon Focus, Greater Weapon Focus, Weapon Specialization,
  Greater Weapon Specialization, Improved Critical) across Pistol, Musket and
  Blunderbuss, with the original blueprint parameters preserved. The four
  higher roots were qualified 12/12 through real level-up selections with
  native prerequisite enforcement, a snapshot-proven cancellation and
  FeatureUIData monogram verification.
- **Guarded runtime qualification**: the 39 racial action consumers render
  through native widgets with exact sprite references, a pinned native
  control observation and full post-cleanup restoration; all qualification
  ran through the established Steam-guarded request mechanism with verified
  installation restoration and no save writes.

## Honest limits (unchanged by this release)

- Ordinary in-game ability-menu navigation, the activatable toggle surface
  and held-touch presentation are covered by a short owner checklist
  (`reports/icon-overhaul/SUPERVISED-NATIVE-FLOW-CHECKLIST.md`); the
  automated fixtures prove native-widget binding and selection data, not
  those screens — those checks are NOT RUN pending owner review.
- Saved firearm parameter persistence is NOT RUN pending explicit owner
  authorization (`reports/icon-overhaul/SAVED-PARAMETER-AUTHORIZATION-REQUEST.md`).
- Final native UI acceptance (including the Wakizashi selector concern at
  the owner's display settings) remains an owner decision; the curated
  review gallery and packet are prepared.

## Compatibility

Install over any previous 0.0.12x version with Unity Mod Manager. The
retained compatibility profiles and feature-module settings are unchanged;
no other mod is required or modified.

- Optional-mod compatibility artifacts are unchanged: the Craft Magic Items
  integration (`CraftMagicItems.dll` references) and every retained
  compatibility profile carry over from 0.0.129 without modification.

- Historical suite checkpoints of 1,251, 1,288 and 1,325 cases remain
  attributed to their original releases; this release ships the complete 1,653-case
  dependency-free domain suite (all passing), which includes every inherited
  checkpoint.
